# 🚀 Gothentic

**Gothentic** is a lightweight, scalable OAuth2 and OpenID Connect (OIDC) server written in Go. Built with a performance-first mindset, it provides a robust identity layer for modern microservices and distributed systems.

## 🛠️ Key Features

- **OAuth2 Compliant:** Supports Authorization Code, Client Credentials, and Refresh Token flows.
- **OIDC Ready:** Standard-compliant identity layer with JWT support.
- **Cloud-Native:** Optimized for Docker and Kubernetes with minimal resource footprint.
- **Pluggable Storage:** Interface-based design supporting PostgreSQL, Redis, or in-memory stores.
- **Security Focused:** Built-in PKCE support and secure token rotation.
